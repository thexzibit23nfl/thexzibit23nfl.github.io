Datenschutzerklärung

Unraid Backup ist eine privat verwendete Anwendung zur Sicherung von Serverdaten.

Die Anwendung nutzt die Google Drive API über rclone, um Backup-Dateien hochzuladen, abzurufen und zu verwalten.

Der Zugriff ist auf Dateien beschränkt, die von der Anwendung erstellt wurden.

Die Backups werden vor dem Hochladen lokal mit rclone crypt verschlüsselt.

OAuth-Zugangsdaten werden lokal auf dem eigenen Server gespeichert. Google Drive dient als Cloud-Speicheranbieter.

Es erfolgt keine Weitergabe von Daten an zusätzliche eigene Webdienste und kein Verkauf personenbezogener Daten.

Der Google-Zugriff kann jederzeit über die Google-Kontoeinstellungen widerrufen werden.
